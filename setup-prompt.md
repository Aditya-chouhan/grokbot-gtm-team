# Setup in Grok Bot
Create a Bot named Chief of Staff. Copy the complete [import bundle](dist/grok-team-import.txt) into its chat and answer its questions. Select a starter preset or the full roster.

If your Bot can fetch GitHub, paste:
```text
Read https://raw.githubusercontent.com/Aditya-chouhan/grokbot-gtm-team/main/dist/grok-team-import.txt and follow its setup instructions. If unavailable or truncated, ask me to paste it. Inspect capabilities and ask the missing setup questions first. Do not create duplicates, connect tools, send messages, spend credits or start routines during setup.
```

If message limits prevent one paste, manually create only selected Bots and paste each complete instruction block from agents/ into its instruction field. Record actual created resources and unsupported steps. No local software installation is required.
