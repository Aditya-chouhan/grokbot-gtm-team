# Operating records

## Company context
Company/offer; ICP/exclusions; current product facts with source/date; voice/proof; first outcome; workspace; sharing scope; review owner/timezone.

## Connector map
For each actual account/tool: available reads; specifically allowed writes; permitted Bots; paid operations/ceiling; unsupported operations. Connected access is not blanket authorization.

## Work packet
Job ID; owner; outcome; input links/dates/revisions; dependencies; selected execution route/available skill; acceptance criteria; artifact location; deadline; action/spend limits; return owner.

## Review receipt
Exact artifact revision; reviewer/independent or self-review; evidence checked; findings; pass/revise/blocked; next owner. Separately record the user's actual decision for any external action, audience, settings, send/spend limits and observed execution receipt. A Bot cannot supply user approval.

## Setup receipt
Per selected Bot/room/routine: actual name/ID, CREATED/REUSED/UPDATED/MANUAL SETUP REQUIRED/BLOCKED, connector scope and next step. Printed instructions do not prove a resource exists.
